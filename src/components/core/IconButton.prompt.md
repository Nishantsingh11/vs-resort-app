**IconButton** — circular, icon-only control for galleries, nav arrows and dialog close.

```jsx
<IconButton label="Next photo" variant="gold"><ChevronRight size={18} /></IconButton>
<IconButton label="Menu" variant="onDark"><Menu size={18} /></IconButton>
```

Variants: `soft` (cream), `outline`, `gold`, `onDark` (for use over imagery / dark headers). Always pass `label` for accessibility.
